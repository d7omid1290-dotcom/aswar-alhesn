# أسوار الحصن

لعبة مسابقات استراتيجية عربية: كل فريق يوزّع عناصره سرًا في مواقع حصنه المرقّمة، وكل إجابة صحيحة تمنحه صاروخًا يطلقه على موقع في حصن خصم.

## التشغيل محليًا

```bash
npm install
npm run dev        # يفتح على http://localhost:5173 ويعمل خادم الشبكة المحلية تلقائيًا
npm test           # 39 اختبارًا للمحرك والخادم
npm run build      # فحص الأنواع وبناء نسخة الإنتاج في dist/
```

يتطلب Node 20 أو أحدث.

## أوضاع التشغيل

| الوضع | متى يظهر | ماذا يفعل |
|---|---|---|
| **هذا الجهاز** | دائمًا | المقدم يدير كل شيء من جهاز واحد. يُحفظ تقدم المباراة في المتصفح، وتتزامن شاشة الجمهور وتبويبات الفرق داخل المتصفح نفسه عبر BroadcastChannel. |
| **الشبكة المحلية** | عند التشغيل بـ `npm run dev` | خادم Vite يعمل كخادم موثوق للمباراة (REST + SSE). تنضم الجوالات المتصلة بالشبكة نفسها عبر رمز QR. الحالة في ذاكرة الخادم. |
| **عبر الإنترنت** | بعد ضبط Supabase على Vercel | دالة `api/[action].ts` هي الحكم، والحالة في Postgres، والبث عبر Supabase Realtime. |

لا يظهر وضع "عبر الإنترنت" إلا إذا ردّ الخادم بأنه مضبوط فعلًا (`/api/health`). لا توجد مفاتيح وهمية في المشروع.

## الواجهات

- `#/` الرئيسية: إنشاء مباراة، أو انضمام فريق برمز الغرفة ورمز الفريق، أو فتح شاشة الجمهور.
- `#/host?room=…` لوحة المقدم: الفرق، توزيع الحصون، الإعدادات، بنك الأسئلة، طرح الأسئلة، التحكيم، اختيار الهدف، الإيقاف، تعديل النقاط بسبب، سجل الأحداث، إعلان الفائز.
- `#/screen?room=…` شاشة الجمهور: الخريطة والمشاهد السينمائية فقط، دون أي بيانات سرية.
- `#/team?room=…&t=…` جوال الفريق: توزيع حصنه، الإجابة، اختيار الهدف.
- `#/lab` مختبر المشهد ثلاثي الأبعاد للمطورين (`?view=fortress&strike=1&kind=king`).

## الأمان

- المحرك (`src/engine/engine.ts`) دالة نقية: `applyCommand(state, cmd, actor)`. كل أمر يُتحقق منه على الخادم: الدور، الدور الحالي، صحة الهدف، منع ضرب النفس، منع ضرب موقع مضروب، ومعرف الطلب لمنع التنفيذ المكرر.
- `projectView` يقصّ الحالة حسب الدور. الجمهور لا يرى أي توزيع. الفريق يرى حصنه فقط. المقدم يرى الكل. الإجابات الصحيحة لا تُرسل للفرق قبل التحكيم.
- شكل المباني على الخريطة ثابت لكل التركيبات (`publicLayout`)، فلا يكشف موقع الملك من شكل الحصن.
- قنوات البث بأسماء سرية: قناة عامة للجمهور، وقناة لكل فريق باسم مشتق من رمزه، وقناة للمقدم.
- جداول Supabase مفعّل عليها RLS دون أي سياسة، ولا يصل إليها المتصفح. الوصول فقط عبر دوال `security definer` تطلب `HISN_SERVER_SECRET` الموجود على الخادم وحده.
- تحديث الحالة بإصدار متفائل (`version`) لمنع التعارض عند الأوامر المتزامنة.

## النشر على Vercel وSupabase

1. في Supabase: افتح SQL Editor ونفّذ `supabase/migrations/001_aswar_alhisn.sql`.
2. اقرأ السر الذي أنشأه الملف:
   ```sql
   select server_secret from hisn_config;
   ```
3. في Vercel: استورد المشروع (الإطار Vite، مجلد الإخراج `dist`)، وأضف متغيرات البيئة:
   - `SUPABASE_URL` و`SUPABASE_ANON_KEY` من إعدادات API في Supabase.
   - `HISN_SERVER_SECRET` القيمة من الخطوة 2.
   - `VITE_SUPABASE_URL` و`VITE_SUPABASE_ANON_KEY` القيم نفسها (للاشتراك في البث من المتصفح).
4. أعد النشر. عند فتح الموقع سيظهر خيار "عبر الإنترنت" في الشاشة الرئيسية.

بدون هذه المتغيرات يعمل الموقع المنشور في وضع "هذا الجهاز" فقط، وترد `/api/*` بالرمز 503.

## بنية المشروع

```
src/engine/      المحرك النقي: الأنواع، القواعد، الإسقاط حسب الدور، الأسئلة الافتراضية
server/          خدمة الغرف المشتركة بين خادم الشبكة المحلية وVercel (ذاكرة أو Supabase)
api/[action].ts  دالة Vercel: health, room, view, command
src/net/         العملاء: محلي (BroadcastChannel) وبعيد (REST + SSE أو Supabase Realtime)
src/game3d/      العالم ثلاثي الأبعاد (three.js): التضاريس، الأنهار، القرى، الحصون، منصات الصواريخ، المؤثرات، الكاميرا السينمائية
src/ui/          الواجهات (React + Tailwind + Radix + Motion)
src/lib/sound.ts الأصوات (Howler) من ملفات public/sfx المولّدة بـ npm run sfx
supabase/        مخطط قاعدة البيانات والصلاحيات
tests/           اختبارات Vitest
```

## ملاحظات

- استُخدم three.js بدل Phaser لأن المطلوب حصون واقعية ثلاثية الأبعاد بكاميرا تقترب وتتابع الصاروخ. كل النماذج والخامات مولّدة برمجيًا، دون ملفات صور خارجية.
- لتخفيف الرسوم على الأجهزة الضعيفة: من الإعدادات اختر "مؤثرات مخففة" أو "بدون مؤثرات"، أو نفّذ في المتصفح `localStorage.setItem('aswar:quality','low')`.
- استيراد الأسئلة: CSV أو Excel بالأعمدة `النوع، السؤال، الخيارات (مفصولة بـ |)، الإجابة، المجال، الصعوبة، الفئة` أو ما يقابلها بالإنجليزية. يوجد قالب للتنزيل داخل بنك الأسئلة.
